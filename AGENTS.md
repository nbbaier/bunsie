# bunsie

## Read before the matching task

- **Editing or reviewing code** → read `CODING_STANDARDS.md` first (rules for `packages/bunsie/src`, plus the validation command).
- **Adding a feature, changing the build pipeline, or exploring the source** → `docs/architecture.md` (module map and build pipeline).
- **Changing CLI, dev-server, or scaffold behavior** → `docs/cli.md`.
- **Filing, reading, commenting on, or closing a GitHub issue** → `docs/agents/issue-tracker.md` (all `gh` commands, including labelling).
- **Triaging issues or deciding which label to apply** → `docs/agents/triage-labels.md` (the canonical label strings).
- **Naming a domain concept or reopening a recorded decision** → `docs/agents/domain.md` (`GLOSSARY.md`, `docs/adr/`).
